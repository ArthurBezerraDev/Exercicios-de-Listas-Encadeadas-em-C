# Exercícios de Listas Ligadas em C 📚

Este repositório contém exercícios práticos de Estruturas de Dados focados na implementação e manipulação de **Listas Ligadas (Linked Lists)** na linguagem C.

## 💻 Ficheiros do Projeto

* **`exercicio_1lista.c`**: Sistema de gestão escolar[cite: 3]. Permite cadastrar alunos através do nome, associar e alterar notas, remover registos em qualquer posição da lista e apresentar a turma, libertando toda a memória dinamicamente alocada no encerramento[cite: 3].
* **`exercicio_2lista.c`**: Sistema de controlo de estacionamento[cite: 2]. Permite adicionar veículos através da matrícula (placa), gerir o tempo de permanência, remover veículos específicos e apresentar o estado atual da garagem[cite: 2].
